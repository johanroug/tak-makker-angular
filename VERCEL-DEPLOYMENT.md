# Vercel er afviklet

Vercel bruges ikke længere, og projektet er slettet. Den tidligere deploymentvejledning er erstattet af [Simply-vejledningen](docs/simply-migration.md).

Hosting styres af `hosting/simply/.htaccess` og `.github/workflows/deploy-simply.yml`. `npm run build:simply` klargør uploadfilerne. Der er ingen Vercel-konfiguration i projektet.
