Vælg Tillad, hvis browseren spørger. Kommer der ingen boks, kan du ændre tilladelsen her:

Safari på iPhone eller iPad
  1. Tryk på sidemenuen ved adresselinjen (sideikonet eller aA).
  2. Åbn Indstillinger til websteder. I nogle versioner ligger de under Mere (…).
  3. Vælg Mikrofon → Tillad for dette websted.
Se Apples vejledning ↗
Chrome på iPhone eller iPad
  1. Åbn telefonens Indstillinger → Apps → Chrome. Du kan også søge efter Chrome i Indstillinger.
  2. Slå Mikrofon til, hvis den er slået fra.
  3. Gå tilbage til Chrome, tryk Prøv mikrofonen igen herunder, og vælg Tillad, hvis webstedet spørger.

Er mikrofonen allerede slået til? Hvis Chrome viser et mikrofonikon ved adresselinjen, kan du åbne det og tillade mikrofonen for dette websted. Ikonet til AI eller søgning er ikke mikrofontilladelsen.

Se Googles iPhone-vejledning ↗
Chrome på Android
  1. Åbn Chromes menu med tre prikker → Indstillinger → Websiteindstillinger → Mikrofon.
  2. Tillad, at websteder kan spørge om mikrofonadgang. Står dette websted under Blokeret, tryk på det og vælg Tillad.
  3. Er mikrofonen stadig blokeret, åbn telefonens Indstillinger → Apps → Chrome → Tilladelser → Mikrofon, og tillad brug af mikrofonen.
Se Googles vejledning ↗
Andre browsere og computer

Åbn browserens tilladelser for dette websted via ikonet ved webadressen. Find Mikrofon, og vælg Tillad. Kontrollér også i enhedens indstillinger, at din browser må bruge mikrofonen.

Vend tilbage hertil, når tilladelsen er ændret. Din tekst bliver stående, og du kan altid skrive videre.
